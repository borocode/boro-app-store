# Boro Labs Community App Store for Umbrel

Sovereign nodes, cypherpunk utilities, and decentralized P2P infrastructure packaged for Umbrel and UmbrelOS.

---

## 📲 How to Install on Umbrel

1. Open your Umbrel dashboard (`http://umbrel.local`).
2. Go to the **App Store**.
3. Click the menu dots in the top right and select **Community App Stores**.
4. Paste this repository URL and click **Add**:
   ```
   https://github.com/borocode/boro-app-store
   ```
5. Click **Open** to browse and install any Boro Labs apps with 1 click!
